# Peaks Hotel — Deployment Folder

Everything cPanel needs to deploy the site.

```
deployment/
├── public_html/        ← Built React frontend (copy contents to public_html)
│   ├── .htaccess       ← React Router SPA rules + caching + security headers
│   ├── index.html      ← (generated by build)
│   └── assets/         ← (generated by build — hashed JS, CSS, images)
├── server/             ← Node.js Express backend
│   ├── server.js       ← Main server entry point
│   ├── src/
│   │   ├── index.js
│   │   └── db.js
│   ├── package.json
│   └── .env.example    ← Copy to .env and fill in real values
├── .cpanel.yml         ← cPanel Git auto-deploy script
├── build-and-copy.sh   ← Run locally before each deploy
└── README.md
```

---

## One-time cPanel Setup

### 1. Git Version Control
- cPanel → Git Version Control → Create
- Clone URL: your GitHub repo
- Repository Path: `/home/$USER/peakshotel` (outside public_html)
- Branch: `main`

### 2. Node.js App
- cPanel → Setup Node.js App → Create Application
- Node.js version: **18** or higher
- Application mode: **Production**
- Application root: `/home/$USER/nodeapp`
- Application URL: your domain (or subdomain for API)
- Application startup file: `server.js`
- Click **Run NPM Install**
- Add all environment variables from `server/.env.example`

### 3. Set environment variables
In the Node.js App panel, add each key from `.env.example` with real values:
- SMTP credentials (Gmail App Password)
- Supabase URL + keys
- M-Pesa Daraja keys
- Paystack key
- `PORT=3001`
- `NODE_ENV=production`

## Deploying Updates

### Step 1 — Build and stage locally
```bash
# From project root:
bash deployment/build-and-copy.sh
```

### Step 2 — Commit and push
```bash
git add deployment/
git commit -m "Deploy: describe what changed"
git push origin main
```

### Step 3 — Pull in cPanel
- cPanel → Git Version Control → your repo → **Pull or Deploy**

The `.cpanel.yml` script will automatically:
1. Copy `deployment/public_html/` → `~/public_html/`
2. Copy `deployment/server/` → `~/nodeapp/`
3. Run `npm install` in `~/nodeapp/`

## API Proxy (important)
The frontend calls `/api/*` endpoints. On cPanel you need to either:

**Option A** — Use `.htaccess` to proxy `/api/` to Node.js port:
```apache
RewriteCond %{REQUEST_URI} ^/api/
RewriteRule ^api/(.*)$ http://localhost:3001/api/$1 [P,L]
```
Add this to `public_html/.htaccess` above the SPA rule, and enable `mod_proxy`.

**Option B** — Run Node.js on a subdomain (e.g. `api.yourdomain.com`) and update `vite.config.ts` proxy targets to point to that subdomain before building.
